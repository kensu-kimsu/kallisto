# Reporting

The experiment automatically tracks:

- daily equity
- weekly performance
- monthly performance
- cumulative return
- drawdown
- S&P 500 benchmark
- Nasdaq-100 benchmark
- API cost

Main outputs include:

- equity comparison chart
- drawdown comparison chart
- four-week mechanical projection
- daily comparison CSV
- weekly summary CSV
- monthly summary CSV

The four-week projection is a mechanical extrapolation of recent weekly returns and is not a market forecast.
